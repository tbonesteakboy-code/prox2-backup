Privacy policy

prox2-backup. Last updated 8 October 2026.

HomePrivacy policyTerms of service

prox2-backup is a private tool used only by its owner to back up the owner's own servers to the owner's own Google Drive.

What Google data it accesses

It requests one Google permission: https://www.googleapis.com/auth/drive.file. With it, the tool can create files and see, update and delete only the files it created. It cannot see any other file in the Google Drive. It does not request the account's name, email, contacts or any other Google data.

How the data is used

  • The only data it uploads is the owner's own server backups, encrypted on the owner's equipment before upload. The encryption keys never leave the owner's control.
  • It reads its own backup files back only to verify them or to restore the owner's servers.
  • It deletes its own backup files after 7 days.

Sharing, selling and storage

No data is shared with, sold to or transferred to anyone. There is no other server, analytics or advertising involved. The Google access token is stored only on the owner's own equipment.

Google API Services User Data Policy

prox2-backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

prox2-backup

A private backup tool.

HomePrivacy policyTerms of service

prox2-backup is a private tool that copies encrypted backups of its owner's own home servers to the owner's own Google Drive. It is used by one person, the owner of the GitHub account tbonesteakboy-code, and is not offered to anyone else.

What it does

  • Once a night, it uploads backup files that are encrypted before they leave the owner's network.
  • It uses Google's drive.file permission, so it can see and manage only the files it created itself. It cannot read, list or change any other file in the Drive.
  • It deletes its own backup copies after 7 days.

There is nothing to sign up for. If you are not the owner, this app is not for you, and you should not authorize it.
